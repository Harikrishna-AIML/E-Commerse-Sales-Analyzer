🛒 E-Commerce Sales Analyzer

A Python-based data analysis project that analyzes e-commerce sales data using Pandas and Matplotlib. This project provides useful insights into sales performance, product popularity, revenue, categories, and payment methods through data analysis and visualization.

📌 Project Overview

The E-Commerce Sales Analyzer is designed to analyze sales data from an e-commerce business.

The project reads sales data from a CSV file and performs data analysis using Python. It calculates important sales metrics and generates charts to understand business performance.

This project helped me improve my skills in Python programming, Pandas, data analysis, and data visualization.

🎯 Objectives

- Analyze e-commerce sales data.
- Calculate total orders, quantity, and revenue.
- Identify the best-selling products.
- Analyze revenue by category.
- Analyze payment methods.
- Calculate monthly average revenue.
- Visualize sales insights using charts.

🛠️ Technologies Used

- Python — Programming language.
- Pandas — Data loading, cleaning, and analysis.
- Matplotlib — Data visualization and charts.
- CSV — Dataset format.
- VS Code — Development environment.
- Git & GitHub — Version control and project hosting.

📊 Features

1. Total Sales Analysis

- Total number of orders.
- Total quantity of products sold.
- Total revenue generated.

2. Product Analysis

- Top-selling product.
- Top 5 best-selling products.
- Total sales for each product.
- Highest-price product.
- Lowest-price product.

3. Category Analysis

- Best-performing category.
- Total quantity sold by category.
- Revenue generated by each category.
- Category-wise sales comparison.

4. Payment Method Analysis

- Revenue generated by each payment method.
- Number of sales using different payment methods.
- Identification of the most-used payment method.

5. Monthly Revenue Analysis

- Average revenue for each month.
- Monthly revenue comparison.
- Monthly revenue visualization.

📈 Data Visualizations

The project includes the following charts:

1. Category vs Quantity Bar Chart
   Shows the total quantity of products sold in each category.

2. Monthly Average Revenue Line Chart
   Shows the average revenue generated per month.

3. Top 5 Best-Selling Products Bar Chart
   Displays the five products with the highest total quantity sold.

These charts make it easier to understand sales trends and product performance.
